00 / OVERVIEW

One field. Every output frame.

Source ↗

Video edges form an x–y–time distance volume. Coarse region density guides finite quaternion, Mandelbox, and sponge recurrences. Their orbit strength and contours supply every output color; source RGB is never composited.

Start with the edge volume, scrub time, and rotate the material axis. Select a module to inspect its implementation contracts and source symbols. The documentation remains available when WebGL or motion is disabled.

Optimization scope: the temporal density solve is convex; the nonlinear fractal fit is heuristic. This is a procedural approximation, not a globally optimal reconstruction or a physical-energy minimum.
